# seatly-api

Domain, orders, tickets and admin API for Seatly, an event ticketing platform with
real-time seat selection.

Owns users, venues, events, seats, orders, payments and tickets. Seat holds belong to
[seatly-realtime](https://github.com/tonixhaker/seatly-realtime) and are not stored here —
a seat in this database is `free` or `sold`.

## Stack

- PHP 8.4, Laravel 12
- PostgreSQL 17
- Sanctum for bearer-token auth
- RabbitMQ for publishing domain events
- Pest, Larastan level 9, Pint

## API

OpenAPI 3.1 in `docs/openapi.json`, generated by `dedoc/scramble`.
Event payload schemas in `docs/events/`.

## Running it

Needs PHP 8.4, Composer, PostgreSQL 17, and a reachable `seatly-realtime` for checkout.

```bash
composer install
cp .env.example .env
php artisan key:generate
php artisan migrate --seed
php artisan serve
```

Serves on `http://localhost:8000`.
